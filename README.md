# Polski: końcówki

Справочник польской грамматики на русском, с опорой на русский и белорусский. Одна страница, восемнадцать разделов, поиск по всему тексту.

**[polski.hamanovich.com](https://polski.hamanovich.com)**

## Что внутри

| Раздел                                         | О чём                                                                                         |
|------------------------------------------------|-----------------------------------------------------------------------------------------------|
| Алфавит                                        | 32 буквы, девять особых, диграфы, ударение, орфографические пары `ch/h`, `rz/ż`, `u/ó`        |
| Род                                            | Мужской род делится на три - отсюда всё остальное                                             |
| Существительные                                | Семь падежей: когда нужен, предлоги, окончания, чередования, подводные камни                  |
| Прилагательные · Местоимения · Числительные    | Одна парадигма на всю группу; что число делает с падежом и глаголом                           |
| Глаголы                                        | Четыре спряжения, времена и вид, наклонения, причастия и пассив, управление, словарь глаголов |
| Вопросы · Отрицание · Порядок слов · Безличные | Как собирается предложение                                                                    |
| Наречия · Предлоги · Союзы · Частицы           | Служебные слова и пунктуация                                                                  |
| Люди · Уменьшительные · Мосты                  | Вежливое «вы», имена и национальности, ласковые формы, ложные друзья                          |

Поиск - по клавише <kbd>/</kbd> или <kbd>⌘K</kbd>: находит строку в любом разделе, открывает нужную вкладку и подсвечивает найденное. По выдаче можно ходить стрелками <kbd>↑</kbd> <kbd>↓</kbd>. Ссылки на конкретный падеж или подраздел живут в адресе: `#s-cases/dop/pl`, `#s-verbs/rekcja`; клик по решётке рядом с подзаголовком копирует ссылку прямо на него.

Тема - светлая или тёмная, переключателем в шапке. Пока выбора не было, справочник следует системной настройке.

## Как запустить

Ни сборки, ни зависимостей, ни сервера. Достаточно склонировать и открыть `index.html`:

```sh
git clone git@github.com:hamanovich/gramatyka-polski.git
cd gramatyka-polski
open index.html
```

Сайт полностью работает по `file://` - это осознанное ограничение, поэтому в коде нет ES-модулей и внешних запросов.

## Структура

```
index.html    каркас: шапка, меню, пустые секции разделов
style.css     палитра через light-dark(), ручная тема на data-theme
data.js       только данные: массивы и объекты, никакой логики
app.js        рендер, навигация, хеш-роутинг, поиск, тема
fulltext.txt  текстовый дамп отрисованного справочника
```

Новый раздел - это массив в `data.js`, функция `render*()` в `app.js`, запись в `TABS` и пустая `<section>` в `index.html`. Поиск и якоря подхватывают его сами.
