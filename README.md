# Polski: końcówki

Справочник польской грамматики на русском, с опорой на русский и белорусский. Главная-оглавление, двадцать одна тематическая страница, план занятий на 40 дней и поиск по всему тексту.

**[polski.hamanovich.com](https://polski.hamanovich.com)**

## Что внутри

| Раздел                                         | О чём                                                                                         |
|------------------------------------------------|-----------------------------------------------------------------------------------------------|
| Алфавит                                        | 32 буквы, девять особых, диграфы, ударение, орфографические пары `ch/h`, `rz/ż`, `u/ó`        |
| Род                                            | Мужской род делится на три - отсюда всё остальное                                             |
| Чередования                                    | Сводная карта `ó/o`, `ą/ę` и изменений согласных                                              |
| Существительные                                | Семь падежей: когда нужен, предлоги, окончания, чередования, подводные камни                  |
| Прилагательные · Местоимения · Числительные    | Одна парадигма на всю группу; что число делает с падежом и глаголом                           |
| Глаголы                                        | Четыре спряжения, времена и вид, наклонения, причастия и пассив, управление, словарь глаголов |
| Словарь · Разговорная практика                 | Более 400 слов с формами и примерами; готовые фразы, конструкторы, мини-диалоги и фразы спасения |
| Вопросы · Отрицание · Порядок слов · Безличные | Как собирается предложение                                                                    |
| Наречия · Предлоги · Союзы · Частицы           | Служебные слова и пунктуация                                                                  |
| Люди · Уменьшительные · Мосты                  | Вежливое «вы», имена и национальности, ласковые формы, ложные друзья                          |

Отдельно лежит [план на 40 дней](https://polski.hamanovich.com/plan-40/) - маршрут до разговорного B1 с разбивкой по дням и ссылками в нужные разделы справочника.

Поиск - по клавише <kbd>/</kbd>, <kbd>⌘K</kbd> или <kbd>Ctrl+K</kbd>: находит строку в любом разделе, открывает нужную страницу и подсвечивает найденное. По выдаче можно ходить стрелками <kbd>↑</kbd> <kbd>↓</kbd>. У каждого раздела есть реальный URL, например `/cases/` или `/verbs/`; выбранный падеж или глагольный подраздел остаётся в fragment: `/cases/#dop/pl`, `/verbs/#rekcja`. Клик по решётке рядом с подзаголовком копирует ссылку прямо на него. Старые ссылки вида `/#s-verbs/czasy` перенаправляются на новые адреса.

Тема - светлая или тёмная, переключателем в шапке. Пока выбора не было, справочник следует системной настройке.

## Как запустить

Готовые HTML-страницы уже предгенерированы и открываются напрямую:

```sh
git clone git@github.com:hamanovich/polski.git
cd polski
open index.html
```

Сайт работает по `file://`: `index.html` ведёт на тематические страницы в соседних каталогах. На каждой странице её контент уже находится в HTML, а `client.js` только добавляет фильтры, глобальный поиск и тему. Без JavaScript страницы и переходы между ними остаются доступными и читаемыми.

После изменения данных или шаблонов нужно пересобрать HTML:

```sh
npm install        # linkedom, единственная зависимость, нужна только для сборки
npm run build      # HTML-страницы, поисковый индекс, sitemap и fulltext.txt
npm run check      # синтаксис скриптов, запрещённые символы и проверки по собранному HTML
npm run verify     # build + check + проверка, что сгенерированное не разошлось с исходниками
```

`npm run verify` гоняет CI на каждый push и pull request. Картинки для соцсетей пересобираются отдельной командой `npm run og`: ей нужен Chrome, и запускать её надо только когда меняется заголовок страницы.

Главный и тематические `index.html` коммитятся вместе с исходниками, поэтому для публикации сервер и Node.js не нужны. GitHub Pages раздаёт каталоги как чистые URL без дополнительной конфигурации.

## Структура

```
index.template.html      HTML-каркас для сборки
404.template.html        каркас страницы 404
data.js                  данные справочника; в браузер не отправляется
app.js                   шаблоны контента; выполняются только при сборке
client.js                progressive enhancement: фильтры, поиск, тема и прямые ссылки
style.css                палитра, адаптивность и режим без JavaScript
scripts/pages.mjs        список страниц: маршрут, h1, title, description
scripts/build.mjs        генерирует HTML-страницы, поисковый индекс, sitemap и fulltext.txt
scripts/check-build.mjs  проверки по собранному HTML; заменяют тесты
scripts/lint-content.mjs запрещённые символы в исходниках и в выводе
scripts/og-images.mjs    рисует og/*.png через headless Chrome, разметка в og-card.mjs
index.html               главная страница-оглавление
*/index.html             двадцать одна тематическая страница
plan-40/index.html       план на 40 дней; написан руками, сборкой не переписывается
404.html                 генерируемая страница ошибки
search-index.js          генерируемый индекс глобального поиска, загружается при обращении к поиску
fulltext.txt             весь текст справочника одним файлом
og/                      картинки для соцсетей и manifest.json с их отпечатками
robots.txt               разрешения для поисковых crawler'ов и ссылка на sitemap
sitemap.xml              список двадцати трёх индексируемых canonical URL
```

Новый раздел - это массив в `data.js`, функция `render*()` в `app.js`, записи в `TABS` и `GROUPS`, пустая `<section>` в `index.template.html`, страница в `scripts/pages.mjs` и маршрут в `scripts/check-build.mjs`. После `npm run build` тематическая страница, поиск, canonical, JSON-LD и sitemap генерируются автоматически; OG-картинку добавляет `npm run og`.
