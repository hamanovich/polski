# Polski: końcówki

Справочник польской грамматики на русском, с опорой на русский и белорусский. Главная-оглавление, девятнадцать тематических страниц и поиск по всему тексту.

**[polski.hamanovich.com](https://polski.hamanovich.com)**

## Что внутри

| Раздел                                         | О чём                                                                                         |
|------------------------------------------------|-----------------------------------------------------------------------------------------------|
| Алфавит                                        | 32 буквы, девять особых, диграфы, ударение, орфографические пары `ch/h`, `rz/ż`, `u/ó`        |
| Род                                            | Мужской род делится на три - отсюда всё остальное                                             |
| Существительные                                | Семь падежей: когда нужен, предлоги, окончания, чередования, подводные камни                  |
| Прилагательные · Местоимения · Числительные    | Одна парадигма на всю группу; что число делает с падежом и глаголом                           |
| Глаголы                                        | Четыре спряжения, времена и вид, наклонения, причастия и пассив, управление, словарь глаголов |
| Вопросы · Отрицание · Порядок слов · Безличные | Как собирается предложение                                                                    |
| Наречия · Предлоги · Союзы · Частицы           | Служебные слова и пунктуация                                                                  |
| Люди · Уменьшительные · Мосты                  | Вежливое «вы», имена и национальности, ласковые формы, ложные друзья                          |

Поиск - по клавише <kbd>/</kbd> или <kbd>⌘K</kbd>: находит строку в любом разделе, открывает нужную страницу и подсвечивает найденное. По выдаче можно ходить стрелками <kbd>↑</kbd> <kbd>↓</kbd>. У каждого раздела есть реальный URL, например `/cases/` или `/verbs/`; выбранный падеж или глагольный подраздел остаётся в fragment: `/cases/#dop/pl`, `/verbs/#rekcja`. Клик по решётке рядом с подзаголовком копирует ссылку прямо на него. Старые ссылки вида `/#s-verbs/czasy` перенаправляются на новые адреса.

Тема - светлая или тёмная, переключателем в шапке. Пока выбора не было, справочник следует системной настройке.

## Как запустить

Готовые HTML-страницы уже предгенерированы и открываются напрямую:

```sh
git clone git@github.com:hamanovich/gramatyka-polski.git
cd gramatyka-polski
open index.html
```

Сайт работает по `file://`: `index.html` ведёт на тематические страницы в соседних каталогах. На каждой странице её контент уже находится в HTML, а `client.js` только добавляет фильтры, глобальный поиск и тему. Без JavaScript страницы и переходы между ними остаются доступными и читаемыми.

После изменения данных или шаблонов нужно пересобрать HTML:

```sh
npm install
npm run build
npm run check
```

Главный и тематические `index.html` коммитятся вместе с исходниками, поэтому для публикации сервер и Node.js не нужны. GitHub Pages раздаёт каталоги как чистые URL без дополнительной конфигурации.

## Структура

```
index.template.html  HTML-каркас для сборки
data.js              данные справочника; в браузер не отправляется
app.js               шаблоны контента; выполняются только при сборке
scripts/build.mjs     генерирует все HTML-страницы, поисковый индекс, sitemap и fulltext.txt
index.html            главная страница-оглавление
*/index.html          девятнадцать тематических HTML-страниц
client.js             progressive enhancement: фильтры, поиск, тема и прямые ссылки
search-index.js       генерируемый индекс глобального поиска, загружается при обращении к поиску
style.css             палитра, адаптивность и режим без JavaScript
robots.txt            разрешения для поисковых crawler'ов и ссылка на sitemap
sitemap.xml           список двадцати индексируемых canonical URL
```

Новый раздел - это массив в `data.js`, функция `render*()` в `app.js`, запись в `TABS`, пустая `<section>` в `index.template.html` и маршрут с метаданными в `scripts/build.mjs`. После `npm run build` тематическая страница, поиск, canonical и sitemap генерируются автоматически.
