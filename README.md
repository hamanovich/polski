# Polski: końcówki

Справочник польской грамматики на русском, с опорой на русский и белорусский. Одна страница, девятнадцать разделов, поиск по всему тексту.

**[polski.hamanovich.com](https://polski.hamanovich.com)**

## Что внутри

| Раздел                                         | О чём                                                                                         |
|------------------------------------------------|-----------------------------------------------------------------------------------------------|
| Алфавит                                        | 32 буквы, девять особых, диграфы, ударение, орфографические пары `ch/h`, `rz/ż`, `u/ó`        |
| Род                                            | Мужской род делится на три - отсюда всё остальное                                             |
| Существительные                                | Семь падежей: когда нужен, предлоги, окончания, чередования, подводные камни                  |
| Прилагательные · Местоимения · Числительные    | Одна парадигма на всю группу; что число делает с падежом и глаголом                           |
| Глаголы                                        | Четыре спряжения, времена и вид, наклонения, причастия и пассив, управление, словарь глаголов |
| Вопросы · Отрицание · Порядок слов · Безличные | Как собирается предложение                                                                    |
| Наречия · Предлоги · Союзы · Частицы           | Служебные слова и пунктуация                                                                  |
| Люди · Уменьшительные · Мосты                  | Вежливое «вы», имена и национальности, ласковые формы, ложные друзья                          |

Поиск - по клавише <kbd>/</kbd> или <kbd>⌘K</kbd>: находит строку в любом разделе, открывает нужную вкладку и подсвечивает найденное. По выдаче можно ходить стрелками <kbd>↑</kbd> <kbd>↓</kbd>. Ссылки на конкретный падеж или подраздел живут в адресе: `#s-cases/dop/pl`, `#s-verbs/rekcja`; клик по решётке рядом с подзаголовком копирует ссылку прямо на него.

Тема - светлая или тёмная, переключателем в шапке. Пока выбора не было, справочник следует системной настройке.

## Как запустить

Готовый `index.html` уже предгенерирован и открывается напрямую:

```sh
git clone git@github.com:hamanovich/gramatyka-polski.git
cd gramatyka-polski
open index.html
```

Сайт полностью работает по `file://`: весь справочник находится в HTML, а `client.js` только добавляет вкладки, фильтры, поиск и тему. Без JavaScript все разделы остаются видимыми и читаемыми.

После изменения данных или шаблонов нужно пересобрать HTML:

```sh
npm install
npm run build
npm run check
```

`index.html` коммитится вместе с исходниками, поэтому для публикации сервер и Node.js не нужны.

## Структура

```
index.template.html  HTML-каркас для сборки
data.js              данные справочника; в браузер не отправляется
app.js               шаблоны контента; выполняются только при сборке
scripts/build.mjs     генерирует полный index.html и fulltext.txt
index.html            готовая страница со всем контентом
client.js             progressive enhancement: вкладки, фильтры, поиск, тема
style.css             палитра, адаптивность и режим без JavaScript
robots.txt            разрешения для поисковых crawler'ов и ссылка на sitemap
sitemap.xml           список индексируемых canonical URL
```

Новый раздел - это массив в `data.js`, функция `render*()` в `app.js`, запись в `TABS` и пустая `<section>` в `index.template.html`. После `npm run build` поиск и якоря подхватывают его автоматически.
